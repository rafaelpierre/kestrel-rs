# Kestrel development journal

This directory is the durable working record for the Rust port. Add one file
per development day using `YYYY-MM-DD.md`. The daily entry should record
completed changes, verification, benchmark evidence, decisions, and the next
starting point.

The active roadmap lives in [`PLAN.md`](PLAN.md). Benchmark data remains under
`benchmarks/results/`; journal entries should link to it rather than duplicate
large result files.
